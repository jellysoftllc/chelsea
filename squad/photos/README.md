# Player Photos

Each player currently has a **placeholder avatar** (`<slug>.png`) — a Chelsea-blue
badge with their squad number and surname, shown in the roster table and at the top
of their profile.

## Replacing with a real photo

Replace the file, keeping the same name, and it updates everywhere automatically:

- Profile `players/cole-palmer.md` → photo `photos/cole-palmer.png`
- Keep the `.png` name (or update the `<img>` path in the profile and roster if you
  switch to `.jpg`).
- Roughly square (e.g. 400×400) looks best.
